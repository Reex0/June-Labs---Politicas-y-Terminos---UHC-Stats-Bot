Política de Privacidad

Última actualización: 8 de septiembre de 2026

Esta Política de Privacidad explica cómo June Labs (en adelante, "June Labs", "nosotros" o "nuestro") recopila, utiliza y protege la información procesada por nuestro bot de Discord (en adelante, "el Bot").

El Bot está diseñado principalmente para comunidades y servidores de UHC (Ultra Hardcore) y tiene como finalidad registrar y gestionar estadísticas relacionadas con el hosteo.

Al añadir o utilizar el Bot en un servidor de Discord, aceptas las prácticas descritas en esta Política de Privacidad.

1. Información que recopilamos

El Bot puede procesar determinada información de Discord necesaria para proporcionar sus funciones.

1.1. Identificadores de Discord

El Bot puede procesar y almacenar:

  • ID de usuario de Discord.
  • ID del servidor de Discord.
  • Información necesaria para asociar correctamente las estadísticas con un usuario y servidor.

Estos identificadores se utilizan principalmente para registrar y consultar las estadísticas correspondientes.

1.2. Mensajes y contenido

El Bot puede leer y procesar mensajes enviados en los canales en los que tenga acceso con el único propósito de detectar y registrar información relacionada con el sistema de hosteo.

Los mensajes se utilizan como fuente de información para determinar los datos que deben registrarse en las estadísticas.

Importante: El contenido completo de los mensajes no se almacena de forma permanente por June Labs. El Bot procesa los mensajes para obtener la información necesaria y posteriormente almacena únicamente los datos derivados necesarios para el funcionamiento del sistema.

Por ejemplo, un mensaje puede ser utilizado para identificar una actividad de hosteo y actualizar las estadísticas correspondientes del usuario.

1.3. Datos estadísticos

Como resultado del procesamiento de los mensajes, el Bot puede almacenar información relacionada con el sistema de hosteo, incluyendo:

  • Puntos de hosteo.
  • Estadísticas personales.
  • Estadísticas del servidor o grupo.
  • Información necesaria para mantener el historial y funcionamiento del sistema de puntuación.
  • ID de usuario y servidor asociados a dichas estadísticas.

Estos datos se utilizan exclusivamente para proporcionar las funciones estadísticas del Bot.

2. Cómo utilizamos la información

La información procesada por el Bot se utiliza para:

  • Detectar actividades relacionadas con el hosteo.
  • Registrar y actualizar puntos.
  • Generar estadísticas personales.
  • Generar estadísticas generales de un servidor o grupo.
  • Asociar correctamente las estadísticas con los usuarios correspondientes.
  • Mantener el funcionamiento del sistema.
  • Detectar y solucionar errores técnicos.
  • Prevenir manipulaciones o usos indebidos del sistema.

Los comandos del Bot están destinados principalmente a consultar las estadísticas personales o las estadísticas generales del servidor.

June Labs no utiliza los mensajes procesados para crear perfiles personales, enviar publicidad, vender información ni realizar actividades ajenas al funcionamiento del Bot.

3. Almacenamiento y conservación

June Labs almacena los datos derivados necesarios para proporcionar las funciones del Bot, como los puntos y estadísticas de hosteo.

El contenido completo de los mensajes procesados no se almacena de forma permanente como parte del funcionamiento normal del Bot.

Los datos estadísticos pueden conservarse mientras sean necesarios para proporcionar las funciones del servicio y mantener los registros correspondientes.

June Labs podrá eliminar datos cuando ya no sean necesarios, cuando un servidor deje de utilizar el Bot o cuando exista una solicitud válida de eliminación, teniendo en cuenta las limitaciones técnicas y legales aplicables.

4. Acceso a la información

June Labs no vende ni alquila la información procesada por el Bot.

Los datos almacenados se utilizan para proporcionar las funciones estadísticas del Bot y pueden ser accesibles mediante los comandos correspondientes a los usuarios autorizados dentro de Discord.

Los administradores de un servidor pueden consultar las estadísticas correspondientes a su comunidad mediante las funciones proporcionadas por el Bot.

El funcionamiento del Bot se encuentra sujeto también a las políticas y condiciones de Discord.

5. Servicios de terceros

El Bot funciona dentro de la plataforma Discord y depende de sus servicios para proporcionar sus funciones.

Discord puede recopilar y procesar información de acuerdo con sus propias políticas y condiciones. June Labs no controla la información que Discord recopila directamente como parte del uso de su plataforma.

El Bot también puede depender de servicios externos necesarios para su funcionamiento técnico. Cuando corresponda, dichos servicios podrán procesar información de acuerdo con sus propias políticas de privacidad.

6. Seguridad

June Labs adopta medidas razonables para proteger los datos almacenados por el Bot frente a accesos no autorizados, pérdida, alteración o uso indebido.

Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

En caso de detectar un incidente que afecte de manera significativa a la información almacenada por el Bot, June Labs tomará las medidas razonablemente necesarias para investigar y solucionar el problema.

7. Datos de menores

El Bot no está diseñado para recopilar deliberadamente información personal adicional de menores de edad.

El Bot procesa principalmente identificadores de Discord y datos estadísticos necesarios para proporcionar sus funciones dentro de los servidores donde se encuentre instalado.

Los usuarios deben cumplir con los requisitos de edad y las condiciones establecidas por Discord.

8. Solicitudes relacionadas con los datos

Si tienes preguntas sobre la información procesada por el Bot, deseas conocer qué datos asociados a tu usuario pueden estar almacenados o deseas solicitar la eliminación de información, puedes contactar con June Labs.

Las solicitudes podrán requerir información suficiente para identificar correctamente los datos correspondientes y evitar que se elimine información perteneciente a otra persona.

9. Eliminación de datos

Cuando sea técnicamente posible y no exista una razón legítima para conservar determinada información, June Labs podrá eliminar los datos asociados a un usuario o servidor previa solicitud.

La eliminación de los datos puede afectar a las estadísticas e historial de puntos asociados al usuario o servidor.

Si un servidor deja de utilizar el Bot, June Labs podrá eliminar los datos asociados a dicho servidor de acuerdo con sus prácticas de conservación de información.

10. Cambios en esta Política de Privacidad

June Labs puede actualizar esta Política de Privacidad cuando sea necesario debido a cambios en el Bot, en nuestras prácticas de tratamiento de información o en los requisitos legales aplicables.

Cuando se realicen cambios importantes, se actualizará la fecha de "Última actualización" indicada al principio del documento.

11. Contacto

Si tienes preguntas, inquietudes o solicitudes relacionadas con esta Política de Privacidad o con el tratamiento de información realizado por el Bot, puedes contactar con June Labs mediante nuestro correo oficial.

12. Aceptación

Al añadir o utilizar el Bot, reconoces que has leído y comprendido esta Política de Privacidad.

Si no estás de acuerdo con las prácticas descritas en ella, debes dejar de utilizar el Bot y retirarlo del servidor correspondiente.
